# Olist E-Commerce Sales & Delivery Dashboard

## 📌 Project Overview
This project features an interactive dashboard built in **Microsoft Excel** using the **Olist Brazilian E-Commerce Public Dataset**. The goal was to transform raw, multi-table transactional data into actionable business insights regarding sales performance, logistics, and customer behavior.

## 🛠️ Tools & Techniques Used
- **Excel Features:** Pivot Tables, Pivot Charts, Slicers, Timeline, GETPIVOTDATA function, Conditional Formatting.
- **Data Cleaning:** Merging multiple tables (Orders, Items, Payments, Customers, Products) and handling date formats.
- **Dashboard Design:** Dark mode UI with interactive filtering by Year, Month, Seller ID, Payment Type, and Product Category.

## 📊 Key Insights & KPIs
The dashboard tracks the following metrics:
- **Average Delivery Delay:** Monitoring the gap between estimated and actual delivery dates.
- **Total Sales & Freight:** Financial performance overview.
- **Top 10 Sellers:** Identifying high-performing sellers by revenue.
- **Top 5 States:** Geographical sales distribution (SP, RJ, MG, etc.).
- **Payment Type Analysis:** Breakdown of transactions via Credit Card, Boleto, Voucher, etc.
- **Sales Trend:** Monthly seasonality analysis for the year 2017.

## 🚀 How to Use
1. Download the `Book1.xlsx` file.
2. Open in Excel (2016 or later recommended).
3. Use the **Slicers** on the right side to filter data by Seller, Payment Type, or Category.
4. Use the **Timeline** to adjust the date range (currently set to 2017).
